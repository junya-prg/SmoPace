# goods.json 運用ガイド（SmoPace セレクト画面）

セレクト画面の商品一覧は、GitHub Pages で配信される
`https://junya-prg.github.io/SmoPace/goods.json` からアプリが起動時・更新時に取得します。
**このファイルを編集して push するだけで、アプリを更新せずに全ユーザーの一覧を差し替えられます。**

取得できない場合は「前回取得したキャッシュ → アプリ内蔵のフォールバック
（`SelectGoodsItem.bundledItems`）」の順で表示されます。

## フィールド一覧

| フィールド | 必須 | 説明 |
|---|---|---|
| `id` | ✅ | 一意なID（英数字とアンダースコア） |
| `title` | ✅ | 商品名（カードの見出し） |
| `subtitle` | | 説明文（2行まで表示） |
| `category` | | `節煙サポート` / `ケース・周辺機器` / `ケア・消臭` のいずれか |
| `systemIcon` | | SF Symbols のアイコン名。画像がない時のビジュアルに使用 |
| `imageUrl` | | 商品画像URL（後述の注意を必読）。`null` ならアイコン表示 |
| `asin` | | Amazon の ASIN。指定すると商品ページへ直接リンク（成約率が高い） |
| `amazonSearchQuery` | | ASIN未指定時に使う Amazon 検索キーワード |
| `tagText` | | カードに表示する小さなタグ（例:「定番」「新生活」） |
| `isPopular` | | `true` で 🔥 Popular バッジを表示 |
| `months` | | 表示する月の配列（例: `[5,6,7,8,9]` = 5〜9月のみ）。`null` は通年 |
| `weight` | | 数値が大きいほど一覧の上位に固定。同じ値の中は毎日自動で順番が入れ替わる |

並び順は「weight 降順 → 同 weight 内は日付シードによる日替わりシャッフル」です。
同じ日は誰が見ても同じ並び、日が変わると自動で入れ替わります。

## ASIN の調べ方

Amazon の商品ページ URL `https://www.amazon.co.jp/dp/XXXXXXXXXX` の
`XXXXXXXXXX`（10桁英数字）が ASIN です。商品ページの「登録情報」欄にも記載があります。

## ⚠️ 商品画像について（重要）

- **Amazon の画像（m.media-amazon.com など）への直リンクは禁止です。**
  Amazon アソシエイト・プログラム運営規約により、画像は PA-API 経由でのみ利用可能で、
  直リンク（ホットリンク）は規約違反としてアカウント停止のリスクがあります。
- **PA-API 5.0** を使えば公式に商品画像URL・価格・レビュー数を取得できますが、
  利用には「アソシエイト登録後 180日以内に 3件以上の売上」が必要です。
  資格を得たら、PA-API で取得した画像URLを `imageUrl` に入れるだけで表示されます。
- それまでは、**自分で権利を持つ画像**（自分で撮影した写真、商用利用可のフリー素材など）を
  この `docs/` 以下（例: `docs/goods-images/xxx.jpg`）に置き、
  `https://junya-prg.github.io/SmoPace/goods-images/xxx.jpg` を `imageUrl` に指定してください。

## ⚠️ 表記の注意（景品表示法）

「No.1」「トレンド1位」「評価4.8」などの優良性・順位の表記は、
客観的な根拠（出典・調査時期）がない限り記載しないでください（優良誤認のリスク）。
`tagText` は「定番」「新生活」「エチケット」のような事実ベースの表現を推奨します。

## ⚠️ App Store 審査の注意

App Store Review ガイドライン 1.4.3 により、タバコ・VAPE 製品の消費を促進する内容や
タバコ販売の仲介はリジェクト対象になり得ます。
VAPE 本体・ニコチン/ノンニコチンスティック等の掲載は避け、
ケース・灰皿・清掃用品・消臭/オーラルケアなどの周辺グッズ中心の構成を推奨します。
